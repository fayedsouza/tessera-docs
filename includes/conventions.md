Sample requests use `curl`. Replace `$TESSERA_TOKEN` with your own API token and
`api.tessera.example` with the host for your region.

Placeholder values appear in `UPPER_SNAKE_CASE`. Anything in that form must be substituted
before the request will work.

Responses shown here are abridged — fields not relevant to the task at hand are omitted.
The API reference carries the complete schema for each object.
