# Get started

Three pages, in order. Together they take about half an hour.

1. **[Quickstart](quickstart.md)** — authenticate, record one event, read it back.
2. **[Authenticate with the API](authentication.md)** — tokens, scopes, rotation, and
   what the failure codes mean.
3. **[The access model](../concepts/access-model.md)** — how to map your own system onto
   principals, resources and events. Read this before you design your event schema, not
   after.

If you are evaluating rather than integrating, the [Quickstart](quickstart.md) alone will
tell you whether the shape of the API fits.
